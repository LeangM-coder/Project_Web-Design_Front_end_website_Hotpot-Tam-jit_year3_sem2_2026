# Project Web Design (Front-End)

Welcome to the front-end repository for **PROJECT_WEB_DESIGN_2026**. This project contains the user interface, styling, and client-side logic for a multi-page web application featuring ordering, customization, and user profile management.

---

The project is organized into modular, page-specific directories. Each page contains its own independent HTML structure, CSS styling, and JavaScript logic.
